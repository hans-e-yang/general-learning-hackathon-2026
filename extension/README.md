# Circlr extension

Chrome MV3 extension (TypeScript, no framework, per spec #2 / #3).

## Scope

- Session ignition from the toolbar action
- Capture policy + buffering
- Side Panel hosting with the Companion iframe between agent and content scripts
- Drop layer for the LMS upload widget

Set up last, after and against contract-freeze work with the `companion/` Next.js app.
